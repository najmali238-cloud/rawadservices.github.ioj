# رواد للحلول الأكاديمية والمهنية

منصة متكاملة تقدم حلولًا أكاديمية ومهنية وتقنية موثوقة للنجاح والتميز. تشمل خدماتنا إعداد التقارير والأبحاث، تصميم المواقع، العروض التقديمية، والاستشارات المهنية[span_2](start_span)[span_2](end_span).

## ✨ مميزات المنصة
- **واجهة عصرية:** تصميم متجاوب (Responsive) ومظلم (Dark Mode) يناسب جميع الأجهزة، مع تأثيرات بصرية جذابة وسريعة[span_3](start_span)[span_3](end_span).
- **أداة صياغة الطلب:** مساعد ذكي لكتابة وتجهيز طلبات العملاء بشكل احترافي للواتساب[span_4](start_span)[span_4](end_span).
- **تتبع الطلبات:** ميزة تتيح للعميل الاستعلام عن حالة ومراحل إنجاز طلبه بكل سهولة[span_5](start_span)[span_5](end_span)[span_6](start_span)[span_6](end_span).
- **آراء العملاء:** نظام تقييم تفاعلي يتيح للعملاء مشاركة تجاربهم وعرضها بشفافية[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
- **لوحة تحكم المشرف (Admin Panel):** لوحة تحكم مدمجة محمية بتسجيل الدخول، تتيح لإدارة الموقع إضافة وتعديل الطلبات، إدارة الآراء، رفع نماذج الأعمال، وتعديل إعدادات الموقع العامة بكل سهولة[span_9](start_span)[span_9](end_span).

## 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** HTML5, CSS3, Vanilla JavaScript[span_10](start_span)[span_10](end_span).
- **قاعدة البيانات والخدمات السحابية (Backend):** Firebase (Firestore Database, Authentication, Cloud Storage)[span_11](start_span)[span_11](end_span).

## ⚙️ إعداد وتشغيل المشروع
الموقع مبرمج ليعمل افتراضياً بـ "وضع تجريبي محلي" لعرض الواجهات دون أخطاء[span_12](start_span)[span_12](end_span). لتفعيل الربط الحقيقي بقاعدة البيانات ولوحة التحكم، يجب اتباع الخطوات التالية:
1. إنشاء مشروع مجاني على **Firebase** وتفعيل خدمات: `Firestore`, `Authentication` (Email/Password), و `Storage`[span_13](start_span)[span_13](end_span).
2. نسخ إعدادات الربط `firebaseConfig` ولصقها في المكان المخصص داخل متغير `FIREBASE_CONFIG` في ملف `index.html`[span_14](start_span)[span_14](end_span).
3. تحديث قواعد الأمان (Security Rules) في Firestore و Storage لضمان حماية بيانات العملاء والسماح للمشرفين فقط بصلاحيات التعديل والحذف ورفع الملفات[span_15](start_span)[span_15](end_span).

*(ملاحظة: يمكنك مراجعة ملف `دليل-ربط-قاعدة-البيانات-5.md` للحصول على الشرح التقني المفصل للربط).*
